# 📧 Email Spam Classifier

A machine learning-based web application that identifies whether an email message is Spam or Ham (Not Spam).

## ✨ Features
- Predicts spam and legitimate messages.
- Text preprocessing and feature extraction.
- Real-time message classification.
- Simple and user-friendly web interface.

## 🛠️ Technologies Used
Python | Flask | Machine Learning | Scikit-learn | TF-IDF | HTML | CSS

## ⚙️ How to Run

```bash
pip install flask pandas scikit-learn
python app.py
```

Open `http://127.0.0.1:5000/` in your browser.
